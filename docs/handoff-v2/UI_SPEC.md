# 세 화면 동작 명세

2026-11-11 검토용 제안. `references/ui-preview.html`을 브라우저에서 열어 메인/게임/클리어를 전환한다. 같은 폴더의 PNG는 이 HTML을 캡처한 화면이다. 출시 게임 화면이나 승인 완료 시안이 아니다.

## 공통

최신 색상과 제공된 두 햄스터 아트를 공유한다. 글씨와 버튼은 HTML/CSS, 보드와 터널은 SVG/코드. 세 화면을 별개의 그림으로 구현하지 않는다. 320px부터 가로 넘침 없이 표시하고 내용이 길면 세로 스크롤한다. PC는 모바일 화면을 중앙에 배치한다. 터치 버튼은 약 44px 이상의 유효 영역을 확보한다.

## 메인 겸 스테이지 선택

- 별도 타이틀 화면 없이 게임명, 짧은 설명과 햄스터를 표시한다.
- 저장된 진행이 있을 때만 이어하기를 표시한다. 단계/판 번호와 현재 이동 수를 함께 보여준다.
- 단계는 데이터에서 읽어 `초급 3×3`, `중급 4×4`, `고급 5×5`처럼 크기를 함께 표시한다. 미래 단계가 늘면 탭 영역을 스크롤하거나 줄바꿈한다.
- 스테이지는 세로 목록. 번호, 완료/잠금 상태, 획득 별과 개인 최고 이동 수를 표시한다. 전체 판 수와 완료 수는 데이터에서 계산한다.
- 9개 그리드로 제한하지 않는다. 아래로 계속 이어지는 목록이며 임의의 빈 잠금 판을 만들지 않는다. 많은 콘텐츠는 구간 표시/추가 로딩을 붙일 수 있으나 이번 시안에서 고정 페이지 수를 요구하지 않는다.
- 입문 전에는 짧은 입문 진입을 우선하고, 입문 후 단계 선택을 제공한다. 현재 시안은 입문 후/기록 있음 상태다.
- 오늘의 도전은 후순위로 구현될 경우의 영역이다. 실제 기능이 없으면 해당 영역을 숨긴다. 예시 날짜는 2026-11-11 KST이며 운영에서 날짜/판을 계산한다.

## 게임

- 상단: 목록 이동, 단계/판, 격자 크기, 현재 이동 수.
- 보드 위: `연결 1/2`와 모든 햄스터 연결 안내. 보너스·별·목표 이동 수·예상 별은 표시하지 않는다.
- 보드 네 변에 행/열 한 칸 이동 버튼. 공급원 행/열은 잠금 표시와 접근 가능한 설명을 준다. 양쪽 방향을 모두 제공한다.
- 보드는 N×N 데이터로 그린다. 예시 화면은 4×4이며 6×6/7×7 전용 조작을 제안하지 않는다.
- 아래: 되돌리기, 재시작, 완료. 완료는 모두 연결된 현재 배치에서만 활성화한다. 끊긴 상태의 비활성/연결된 상태의 활성 두 상태를 구현한다.
- 조건 달성 후에도 사용자가 완료를 누를 때까지 보드를 유지한다. 완료로 기록을 한 번 저장한 뒤 팝업을 표시한다.
- 목록 이동 후 이어하기가 가능해야 한다. 재시작은 시작 배치/0수, 되돌리기는 이전 배치/수 복원.

## 클리어 팝업

- 같은 게임 화면을 어둡게 덮고 중앙 팝업을 띄운다. 배경 보드에도 보너스 별표는 없다.
- 성공 햄스터, `배달 완료!`, 획득 별, 사용 이동 수를 표시한다. 시안은 별 2개/8수라는 예시이며 평가식이 아니다.
- 기본 동작: 다음 판, 재도전, 공유, 목록. 별 1개도 다음 판 가능. 마지막 판이면 다음 판 대신 단계 목록으로 간다.
- 공유를 구현하지 않았다면 버튼을 숨긴다. 시안의 공유는 실제 API를 호출하지 않는다.
- 배경 입력을 막고 포커스를 팝업에 유지한다. 배경 터치로 팝업을 닫지 않는다. 목록/재도전으로 명시적으로 이동한다.
- 필요한 경우에만 획득 별의 짧은 등장 효과를 적용한다. 몸 변형은 이번 시안에 없다. 동작 줄이기를 존중한다.

## 시안의 범위

미리보기는 화면 선택·단계 탭·예시 연결 상태 전환용이다. 이동 버튼은 출시 규칙을 실행하지 않는다. 판/수/별/기록은 예시다. 표시 경로는 연결 상태를 시각적으로 일치시킨 샘플이며 출시 판의 생성·난이도 검증을 대체하지 않는다. 실제 퍼즐 테스트는 Claude가 공통 규칙으로 수행한다.
