# 현재 구현과 최신 명세의 차이

2026-11-11 파일 확인 결과. 독립적인 정적 확인이며 출시 검증이나 전체 코드 리뷰가 아니다. 이번 전달 작업에서는 게임 소스를 수정하지 않았다.

| 위치 | 현재 확인한 내용 | Claude 수정 항목 |
|---|---|---|
| package.json, src/**/*.js | Vite + JavaScript, 타입 검사 명령 없음 | 기존 모듈을 TS로 전환, strict 타입 검사 명령 추가 |
| src/core/rules.js | b 타일, bonus 분류, 필수만으로 완료 가능, 보너스 별 평가 | 목표를 하나로 통합하고 전부 동시 연결로 완료 판정 |
| src/ui/play.js | 목표 이동 수 칩, 별 기준/예상 별, 보너스 상태/결과 | 플레이 중 현재 이동 수와 전체 목표 연결 상태만 표시 |
| src/ui/board.js | 보너스 타일 렌더 경로 포함 | 보너스 표식 제거, 모든 햄스터 동일 목표 표현 |
| src/game/progress.js, src/storage/storage.js | bestBonus/daily bonus 기록 | 신규 저장 타입과 변환/콘텐츠 버전 분리 검토 |
| src/game/links.js | 보너스 공유 문구 경로 포함 | 공유 결과에서 제거 |
| tools/generate.js, src/data/stages.json | 초급 3/4 혼합, 고급 4/5 혼합, 보너스 판 포함 | 크기별 단계 고정 및 새 목표 조건으로 재생/해답 검증 |
| src/ui/home.js, src/data/parse.js | 단계 목록/그룹이 코드에 고정 | 단계 정의를 데이터에서 읽고 크기/판 수 확장 지원 |
| src/core/rules.js validateStage | 허용 크기 [3,4,5] 및 중앙 공급원 제한 | N×N 검증/단계 설정과 분리. 중앙 고정을 새 요구로 취급하지 않음 |
| docs/STAGE_REPORT.md | 구버전 목표·별 기준 보고서 | 새 규칙과 데이터 생성 뒤 재작성; 현재 보고서를 합격 증거로 재사용하지 않음 |

이미 구현된 모듈 경계·되돌리기·저장·광고 어댑터 등의 재사용 가능성은 실제 검사로 판단한다. 구조가 있다는 사실만으로 동작 합격을 주장하지 않는다. 구버전 테스트가 통과해도 최신 명세 일치는 별도 검증해야 한다.

미확정: 별 평가 수치, 크기별 풀이 길이, 출시 판 수, 후순위 기능 출시 범위, 광고 사업자/배포 경로, 선택 애니메이션.
