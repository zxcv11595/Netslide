# Codex 제작 요청: 로딩 화면 그림

요청일 2026-11-11. 요청자: 프로젝트 오너(Claude Code가 정리).

## 무엇을 만드나

"햄스터 간식 배달" 앱을 켜면 잠깐 보이는 로딩 화면의 그림입니다.
`loading-reference.png`가 Claude가 코드로 그린 배치 시안입니다. 이 배치와 분위기를 유지하면서,
코드로 그린 단순한 배경을 실제 일러스트 수준으로 올려 주세요.

같은 폴더의 `home-reference.png`, `play-reference.png`는 확정된 게임 화면 톤(위는 하늘과 풀밭, 아래는 땅속 굴)입니다.
로딩 화면이 이 두 화면과 한 게임처럼 보여야 합니다.

## 납품물

1. **배경 일러스트** `loading-bg.png` — 1080×2400, 불투명.
   - 위쪽: 옅은 하늘(연한 하늘색 → 크림색), 구름 약간.
   - 가운데 아래: 초록 풀밭 언덕.
   - 아래쪽 약 30%: 갈색 흙 단면. 굴과 씨앗 몇 개가 보이면 좋습니다.
   - 햄스터와 글자는 넣지 않습니다(아래 2, 3번을 코드로 얹습니다).
   - 가운데 1080×1600 영역이 안전 영역입니다. 화면 비율에 따라 위아래가 잘려도 어색하지 않아야 합니다.
2. **게임 이름 로고** `logo-ko.png`, `logo-en.png` — 가로 900 안팎, 투명 배경.
   - 한국어: "햄스터 간식 배달" (두 줄 가능)
   - 영어: "Hamster Snack Delivery" (가칭, 두 줄 가능)
   - 짙은 갈색 외곽선의 둥글고 통통한 글씨. 씨앗이나 햄스터 귀 같은 작은 장식 가능.
3. **(선택) 로딩 화면용 햄스터 포즈** `hamster-loading.png` — 투명 배경, 기존 `hamster-idle.png`와 같은 캔버스 비율(1312×1199).
   - 기존 캐릭터와 완전히 같은 모습(황금빛 주황과 크림색 털, 이마의 갈색 줄무늬 3개, 분홍 귀 안쪽, 분홍 볼, 짙은 갈색 외곽선).
   - 씨앗을 품에 안고 배달하러 가는 느낌. 없으면 기존 `hamster-idle.png`를 그대로 씁니다.

## 지켜야 할 것

- 기존 캐릭터 그림(`art-src/assets/hamster-idle.png`, `hamster-success.png`, `snack-seed.png`)과 선 굵기, 색, 그림자 없는 평면 2D 스타일을 맞춥니다.
- 색 기준: 하늘 #CFEAF2 → #FDF1D2, 풀 #8FBF5A(테두리 #6C9C3D), 흙 #7A5536, 짙은 흙 #4A3018, 굴 #ECD5AA, 간식이 흐르는 굴 #FFBE4A, 글씨와 외곽선 #4A2F18, 포인트 주황 #F29A2E.
- 로딩 막대, 버전 표기, 버튼은 그림에 넣지 않습니다. 코드로 그립니다.
- 로고 외에는 글자를 그림에 굽지 않습니다.
- 다른 게임이나 캐릭터를 떠올리게 하는 요소는 넣지 않습니다.

## 참고

- 로딩이 끝나면 자동으로 홈 화면으로 넘어가며, "눌러서 시작" 단계는 없습니다.
- 결과물은 `art-src/loading/`에 넣어 주세요. 게임 적용(크기 조정, 배치, 로딩 막대)은 Claude Code가 합니다.
